# Stock Candlestick Visualizer

A lightweight Python utility to fetch real-time and historical stock data and plot custom, dark-themed candlestick charts using `mplfinance` and `yfinance`.

---

## Features

- **Multi-Market Support:** Fetch daily price history for Indian (NSE/BSE) and US equities (e.g., `INFY.NS`, `TCS.NS`, `AAPL`).
- **Data Pipeline:** Cleans and flattens `yfinance` MultiIndex data structures automatically using `pandas`.
- **Custom Dark Theme:** Built-in high-contrast dark aesthetic tailored for clear visualization of volume and price action.

---

## Tech Stack

- **Language:** Python 3.10+
- **Libraries:** 
  - `yfinance` - Financial market data extraction
  - `mplfinance` - Financial plotting and candlestick generation
  - `pandas` - DataFrame cleaning and manipulation
